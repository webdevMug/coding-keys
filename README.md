# Coding Keyboard (v2)

Android keyboard for coding on the go: full QWERTY page, a SYM toggle for coding symbols,
auto-pairing brackets and quotes, arrow and undo/redo keys. Long-press the comma key to open settings.

## Build with GitHub Actions
1. Create a new GitHub repository and upload everything in this folder (including the `.github` folder).
2. Open the Actions tab, pick "Build APK", and run it (it also runs on every push).
3. When it finishes, download the `coding-keyboard-debug-apk` artifact and install `app-debug.apk`.
4. Open the app, tap "Enable keyboard", then "Switch to Coding Keyboard".
